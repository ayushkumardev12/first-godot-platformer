# 🎮 First 2D Platformer (Work in Progress)

A 2D platformer game built in **Godot 4** using **GDScript**. This project is a learning exercise focused on mastering core game development mechanics, level design, and scene management in Godot.

---

## 🚀 Current Progress & Features

- **Player Movement:** Smooth platformer controls including running, jumping, and gravity physics.
- **Level Design:** Built using Godot 4 `TileMapLayer` nodes with distinct foreground terrain and background decorative layers.
- **Game Objects & Collectibles:** Animated coins and collectibles placed throughout the level.
- **Hazards & Resets:** Area detection for hazards (`Killzone`) that triggers a temporary time slowdown before reloading the current scene upon player death.
- **Custom UI:** Text labels and custom pixel-art fonts installed for player instructions.

---

## 🛠️ Built With

* [Godot Engine 4](https://godotengine.org/) - 2D Game Engine
* **GDScript** - Scripting language
* **Pixel Art Assets** - Custom tilemaps and character spritesheets
